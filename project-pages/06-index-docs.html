Markera

Kotlin MultiplatformComposeYOLOv8 ONNXML KitApple VisionAndroid · iOS

Overview

Scores precision-shooting series from a single photo of the target. All detection is on-device.

Seven approaches were tried for finding the rings. The full log, with screenshots of each, is in the detection write-up.

Pipeline

  1. HoleDetector — YOLOv8 boxes every hole.
  2. DigitCentre — OCR the ring digits, fit a line per row, intersect.
  3. RimProbes — four disks walk to the 6/7 rim; fit an ellipse.
  4. Scorer — rotate onto ellipse axes, un-squash, gauge by edge.
val centre = digitRows.horizontal intersect digitRows.vertical
val rim    = probes.map { it.walkToEdge(image) }.fitEllipse()
val score  = holes.map { rim.ringValue(it.edgeNearestCentre()) }

The app

Set the dial, hear the commands

The timer calls out the standardized range commands from a dial you set by pinch and drag, with training and competition modes. One Kotlin/Compose Multiplatform codebase shipped to both Google Play and the App Store.

Numbered flags on the dial mark each part of a series and can be dragged into place, with a haptic tick as they snap. Tapping a command jumps the timer to it, competition mode asks the range questions — ready to load, all done, inspection — before it starts, and a short tutorial walks a first-time user through the dial. The commands are spoken in Swedish by a voice that works offline, and everything the app knows stays on the phone.

The testing

Every gesture tested on both platforms

About 150 shared tests check the commands, the timer plans, the dial geometry, the tutorial and the state machine that drives a run. 54 Compose UI tests perform the real gestures — pinching the dial, scrubbing the hand, dragging the flags, the menus and confirmations — and run on the JVM and in the iOS simulator.

GitHub Actions builds and tests Android on Linux and iOS on macOS for every change, and the App Store screenshots are taken by a UI test.

The effects

61 of them, four layers deep

Fractal fire, plasma, copper and Kefrens bars, raymarched Mandelbulbs and Menger sponges — stackable four layers deep with per-layer palettes and filters, and beat-reactive to whatever music you're playing.

The gallery

Publish a scene

Scenes can be published to a public gallery anyone can browse, and a built-in AI-generated collection ships with the app.

Two or more layers can share one 3D world, so their geometry is ray-traced together and a glass shape in one refracts the shapes of another. Auto-cycle moves from scene to scene on its own, blending each change while both scenes keep running, and plays only the scenes you have hearted once you sign in. Profiles sign in with Google or Apple and live on KickTro's own small API server.

The testing

Probes on every push, the GPU before every release

35 Node probes check the effects, the scenes, the controls and the server, a build check confirms the shipped page matches the source, and another keeps the README's list of effects complete. GitHub Actions runs them all on every push to main and every pull request.

Before each release two more checks run on a real graphics card: a startup gate fails the build if the first frame takes longer than 20 seconds, and about 17 headless browser checks render the effects and fail on any draw the driver rejects.

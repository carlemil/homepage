The board

Six lanes, one SQLite file

A lane board — todo, plan, develop, test, verify, done — that I drag cards around in the browser while Claude Code agents work the same cards over MCP, both against one SQLite file.

The agents

Plan, ask, build, deploy

A card assigned to the agent, or left on auto advance, gets headless Claude run in the project's own git worktree: it plans first and hands back questions for me to answer, then builds, tests and pushes the card's branch, and deploys from verify.

The log

Who did what

Every write appends an event with its actor, so each card carries who did what. One process, two dependencies, no build step — and this page is built on it, card by card.
